Cited answers over mainframe manuals, inside an air-gapped cluster

Mainframe RAG is a citation-first question-answering service for a large private corpus of mainframe manuals. It runs on air-gapped OpenShift with no runtime downloads and no cloud inference, and every answer carries exact citations: document number, title, heading path and printed page label.

What it does

Hybrid retrieval

Dense embeddings and BM25 sparse vectors in Qdrant, fused with weighted reciprocal rank fusion. Search itself never calls a language model.

Evidence-first answers

A reasoning model drafts the answer from supplied evidence. The service labels the outcome and declines with an explicit state when the evidence is insufficient.

Air-gap native

Pinned images, wheels and BM25 weights, delivered as a signed bundle. Models are consumed over HTTP through the platform team’s gateway.

Measured, not asserted

A dev golden set, a frozen holdout, pre-registered adoption rules and paired statistics decide what ships.
